CONTEXTO DEL PROYECTO (RESUMEN)

Estoy desarrollando un sistema de combate en Unreal Engine (Blueprints) inspirado en juegos tipo For Honor.

⚔️ SISTEMAS YA IMPLEMENTADOS
1. Sistema de ataque base

Uso de F_AttackData

Tipos de ataque:

Light

Heavy

Direcciones:

Left / Right / Top

Uso de AttackMontage por ataque

2. Flujo del ataque

Estados manejados con variables:

AttackState

None

Attacking

Recovery

CombatState

Normal

Exhausted

Stunned

Flujo:

StartAttack
→ Attacking
→ (Hit / Block)
→ Recovery (notify)
→ EndCurrentAttack
→ None
3. Sistema de trazas (weapon traces)

Funciones:

StartEquippedWeaponTrace

StopEquippedWeaponTrace

Se activan con AnimNotifies

Detecta múltiples enemigos sin repetición

Llama a:

HandleTraceHit

ProcessHit

ReceiveAttack en el enemigo

4. Sistema de daño y bloqueo

En ReceiveAttack:

Se usa CompareAttackAndGuardDirections

Si coincide dirección + LockOn:

Block

Si no:

daño

5. Sistema de stamina
Consumo

ConsumeStamina

Si llega a 0:

CombatState = Exhausted

Exhausted

Ataques siguen funcionando

Pero:

animación más lenta

sin cancel

sin combos

Regen de stamina

Función HandleStaminaRegen

Usa:

StaminaRegenRate

StaminaRegenDelay

LastStaminaUseTime

No regenera si:

Attacking

Recovery

Stunned

Sale de Exhausted SOLO cuando:

Stamina >= MaxStamina
6. Selección de ataque según estado

Función:

GetAttackDataByState

Si CombatState == Exhausted
→ usa ataques exhausted

Si no
→ ataques normales

Incluye:

Light exhausted

Heavy exhausted

7. UI de stamina (world widget)

Widget Component encima del personaje

WBP_StaminaBar

ProgressBar:

se actualiza en Tick

cambia color si Exhausted

Widget rota hacia la cámara (UpdateStaminaWidgetFacing)

8. AnimNotifies usados

AN_StartWeaponTrace

AN_StopWeaponTrace

AN_AttackCancelStart

AN_AttackCancelEnd

AN_AttackRecovery

AN_AttackFinished
